# OffCampus

OffCampus is a full-stack social media platform developed
for CodeAlpha Full Stack Development Internship

## Features

- User registration and login
- User profiles and profile editing
- Create and view posts
- Like and comment on posts
- Follow users and manage followers
- Upload and view photos and videos
- Responsive interface for mobile and desktop

## Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js and Express.js
- Database: SQLite

## Run Locally

1. Install Node.js.
2. Clone this repository.
3. Open the project folder in your terminal.
4. Install dependencies:

   npm install

5. Create a local environment configuration if required.
6. Start the application using the command configured
   in package.json.
